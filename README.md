## 구성과 게시

HTML/CSS/JavaScript로 만든 정적 사이트입니다. 외부 라이브러리, 폰트, 분석 코드, 광고 SDK, 회원가입 폼, 쿠키 및 저장소 기록 기능을 추가하지 않았습니다. 이메일 주소 복사와 이메일 앱 열기 기능을 제공합니다. Woodline은 출시 준비 상태로 표시되어 있습니다. 실제 출시 후 확인된 스토어 다운로드 주소를 추가하십시오. 보드 그림은 플레이 예시이며 홈페이지에서 게임이 실행되지는 않습니다.

이 저장소는 `sailaway-app/sailaway-app.github.io`이며 main 브랜치 루트에서 GitHub Pages로 게시됩니다. 기존 `letterfly-app/letterfly-app.github.io`(Letterfly의 `app-ads.txt` 포함)와 저장소 `letterfly-app/Letterfly`는 Letterfly의 스토어 링크가 걸려 있어 그대로 유지합니다. `app-ads.txt`는 이 주소에도 같은 내용을 두었습니다.

## 정책 문구

개인정보처리방침은 앱 안의 방침과 같은 내용을 담습니다. 실제 Google·Apple 로그인, 배너와 전체 화면 광고, AdMob·Unity Ads 미디에이션, 비개인화 광고 요청이 포함됩니다. 약관에는 회사명과 이메일만 담았습니다. 분석 기능이나 클라우드 저장을 추가하면 실제 처리 정보와 스토어 요구사항에 맞춰 방침을 업데이트해야 합니다. 이 문구만으로 출시 심사 충족 여부를 보장하지는 않습니다.

웹 호스팅의 접속 기록 처리는 별도입니다. GitHub 개인정보 안내: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement
