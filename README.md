## 구성과 게시

HTML/CSS/JavaScript로 만든 정적 사이트입니다. 외부 라이브러리, 폰트, 분석 코드, 광고 SDK, 회원가입 폼, 쿠키 및 저장소 기록 기능을 추가하지 않았습니다. 이메일 주소 복사와 이메일 앱 열기 기능을 제공합니다. Woodline은 출시 준비 상태로 표시되어 있습니다. 실제 출시 후 확인된 스토어 다운로드 주소를 추가하십시오. 보드 그림은 플레이 예시이며 홈페이지에서 게임이 실행되지는 않습니다.

기존 `letterfly-app/letterfly-app.github.io` 저장소의 기본 Pages 게시 방식을 사용합니다. 기존 `app-ads.txt`와 별도 저장소인 `letterfly-app/Letterfly`는 수정하지 않습니다. Pages 설정이 필요한 경우 Settings → Pages → Deploy from a branch → main → /(root)를 선택하십시오.

## 정책 문구

개인정보처리방침은 승인된 Woodline 앱 문구를 옮겼으며, 실제 Google·Apple 계정 연동이 없는 현재 버전을 설명합니다. 약관에는 요청대로 회사명과 이메일만 담았습니다. 실제 로그인, 광고 SDK, 분석 기능, 클라우드 저장을 추가하면 실제 처리 정보와 스토어 요구사항에 맞춰 정책을 업데이트해야 합니다. 현재 문구만으로 출시 심사 충족 여부를 보장하지 않습니다.

웹 호스팅의 접속 기록 처리는 별도입니다. GitHub 개인정보 안내: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement

## 로컬 미리보기

이 폴더에서 `python -m http.server 8080` 실행 후 `http://localhost:8080/`을 여십시오. 파일 직접 열기에서는 브라우저의 클립보드 제한이 있을 수 있습니다.
